# Database Systems – University Project

## Project Overview
This project demonstrates database design, conceptual and logical data modelling, relational mapping, and database technology evaluation.

Developed as part of the Database Systems module at the University of Westminster.

## Project Components

### 1. Conceptual Database Design – Westlivingster
- Evaluated an AI-generated Enhanced Entity Relationship Diagram (EERD).
- Designed a conceptual EERD using UML modelling conventions.
- Identified entities, attributes, relationships, multiplicities, and specialisation constraints.
- Created a data dictionary documenting the database structure.

### 2. Logical Database Design – Tourmato
- Developed a logical Entity Relationship Diagram (ERD).
- Applied relational mapping rules to conceptual database structures.
- Identified primary keys, foreign keys, and relationships.
- Documented the transformation process using a mapping log.

### 3. Relational vs NoSQL Database Analysis
- Compared relational and document-oriented database approaches.
- Evaluated PostgreSQL and MongoDB for booking management, transaction consistency, concurrency, and data retrieval.
- Recommended a relational database architecture based on system requirements.
